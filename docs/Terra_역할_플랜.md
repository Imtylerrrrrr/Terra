# Terra — 캠퍼스의 안부 · 역할 & 진행 플랜

## 0. 제품 방향 (확정)
- **플랫폼**: **웹앱** (React + Vite, Amplify Hosting). three.js는 브라우저에서 직접 렌더 — README 스택 확정.
- **컨셉**: 지속가능성 + **키우기 게임 · 도감 수집** 감성 — 탄소를 줄이면 동물·풍력발전소 등을 도감으로 모은다.
- **입력 4종**: 식단 · 스크린타임 · 영수증 · 전력.
- **행성 3계층**: 캠퍼스별 행성계 → 학과별 행성 → 개인 행성.
- **매핑**: 크기 = 인원당 참여 비율(참여율) · 깨끗한 정도 = 참여 인원 평균(배출량 평균).

## 1. 큰 역할 (아이디어 노트 기반 · 세부 분담은 1일차 협의)

| 구분 | 담당 | 큰 역할 |
|---|---|---|
| AI/데이터 | **민지님** | Bedrock 멀티모달·RAG 계수 매핑, 공공/가상 데이터 파이프라인 |
| PM/백엔드 | **주영** | PM·기획·발표 총괄 + 백엔드·AWS(Lambda/API Gateway)·**계산엔진**·Bedrock/DynamoDB 연동·**전체 통합** (Cloud 20점 책임) |
| 프론트엔드 | 연성님 | **Kiro 스캐폴딩**으로 앱 구현 + **three.js** 캠퍼스 행성계·학과/개인 행성·도감 (3D 메인) + 입력 UX |
| 데이터 + 화면 | 관성님 | 가상 학생·식단·스크린타임·영수증·전력 데이터 생성 + 입력→결과 화면 |
| UX·디자인 + 발표 | 승빈님 | 화면 설계·비주얼(사용성 10점) + 발표자료(6단계)·시연영상 |


## 2. 스택 (확정 — README 기준)

> 단일 진실은 **README.md 기술 스택 표**. 아래는 요약.

| 영역 | 확정 | 비고 |
|---|---|---|
| AI 추출 | **Amazon Bedrock** (Claude 멀티모달) | 식단·영수증 사진 → 품목·수량 |
| 계수/RAG | **Bedrock Knowledge Base** | 식품·전력 등 배출계수 |
| 백엔드 | **AWS Lambda** + **API Gateway**(HTTP API) | 입력 처리·계산엔진·조회 |
| DB | **DynamoDB** | 사용자·학과·캠퍼스·배출량·도감 |
| 파일 | **S3** | 업로드 원본 + 계수 데이터셋 |
| 인증 | **Cognito** | 로그인·학과 소속 (플러스) |
| 프론트 | **React + Vite + TypeScript** | 입력 UX·결과 화면 |
| 3D | **three.js** (로우폴리) | 행성계·행성·도감, 기존 자산 재활용 |
| 호스팅 | **Amplify Hosting** (or S3+CloudFront) | 웹앱 배포·CDN |
| 모니터링 | **CloudWatch** | Lambda 로그·지표 |
| 데이터 | 공공 배출계수 + 생성형 AI 가상데이터 | 하이브리드 |

## 3. 진행 흐름 (무박 2일)

```
1일차 오후  ─ [전원] 스택 확정 + 데이터 형식 합의 + 플로우 확정
            └ 주영: 백엔드·API 규격 / 민지님: AI 시작 / 연성님: 3D·화면 / 관성님: 데이터 / 승빈님: 디자인
1일차 밤    ─ 주영: 계산엔진·통합 / 민지님: 계수매핑 / 연성님·관성님: 구현 / 승빈님: PPT 초안
2일차 오전  ─ 주영: 전체 통합·버그 / 전원: 모듈 마감 / 승빈님: 리허설·영상
2일차 발표  ─ 5분 발표 + Q&A 3분 (발표자: 심주영)
```

## 4. 의존성 (누가 누구를 기다리나)

```
        ┌─ 민지님 (AI: 품목·수량 추출) ──┐
입력 ───┤                            ├──→ 주영 (계산엔진 ×계수 / 집계) ──→ 연성님 (행성 반영: 개인→학과→캠퍼스계 + 도감)
        └─ 관성님 (가상데이터/DB) ───────┘
                                         ↑
                              연성님 (프론트 연결) / 승빈님 (디자인)
```

**핵심 체크포인트 (여기 막히면 전체 지연):**
- ⚠️ **아이디어 확정점** -> 시작전 점검
- ⚠️ **JSON 형식 합의** → 1일차 최우선
- ⚠️ **디자인/플로우(승빈님)는 모두의 작업 기준** → 1일차에 먼저 확정
