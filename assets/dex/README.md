# 도감 동물 일러스트

도감 카드 썸네일로 쓰이는 이미지를 여기에 둡니다. 파일명은 종 id와 동일하게 `<id>.png`.
파일이 없으면 코드가 자동으로 로우폴리 실루엣으로 대체합니다.

| id | 종 |
|---|---|
| `red_fox` | 여우 |
| `otter` | 수달 |
| `goral` | 산양 |
| `sika_deer` | 대륙사슴 |
| `least_weasel` | 무산쇠족제비 |
| `spotted_seal` | 물범 |
| `lynx` | 스라소니 |
| `golden_bat` | 붉은박쥐 |
| `tube_nosed_bat` | 작은관코박쥐 |
| `musk_deer` | 사향노루 |
| `asiatic_black_bear` | 반달가슴곰 |
| `wolf` | 늑대 |
| `leopard` | 표범 |
| `tiger` | 호랑이 |

예) 늑대 일러스트 → `assets/dex/wolf.png`
