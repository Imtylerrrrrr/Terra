# Terra — 캠퍼스의 안부 🌱

> 캠퍼스의 일상(식단·통학·전력)을 탄소배출량으로 환산하고,
> 학과별 **3D 행성**과 **캠퍼스 우주**로 시각화하는 AWS 기반 서비스.

AWS 해커톤(무박 2일) 출품작입니다.

---

## 핵심 아이디어

1. **입력** — 캠퍼스 활동 데이터(식단·통학 등)를 입력
2. **AI 추출** — Amazon Bedrock(Claude 멀티모달)이 품목·수량을 추출
3. **계산엔진** — 추출 결과 × 배출계수(식품·전력·교통)로 탄소배출량 산출
4. **시각화** — three.js로 학과별 행성·캠퍼스 우주에 결과를 반영

배출계수는 공공 데이터와 생성형 AI 기반 가상 데이터를 함께 사용하는 하이브리드 방식입니다.

## 기술 스택 (후보 · 현장 확정)

| 영역 | 1순위 | 비고 |
|---|---|---|
| AI | Amazon Bedrock (Claude 멀티모달) | 대회 요건(AWS) |
| 백엔드 | AWS Lambda (서버리스) | + API Gateway |
| DB | DynamoDB / Supabase | 협의 |
| 계수·RAG | Bedrock Knowledge Base | 식품·전력·교통 계수 |
| 프론트 | Kiro 스캐폴딩 + 웹 | |
| 3D | three.js (로우폴리) | 학과 행성·캠퍼스 우주 |
| 데이터 | 공공 배출계수 + AI 가상데이터 | 하이브리드 |

## 팀 & 역할

| 구분 | 담당 | 역할 |
|---|---|---|
| AI/데이터 | 민지 | Bedrock 멀티모달·RAG 계수 매핑, 데이터 파이프라인 |
| PM/백엔드 | 주영 | PM·기획·발표 총괄, 백엔드·AWS·계산엔진·전체 통합 |
| 프론트엔드 | 연성 | Kiro 화면 구현, three.js 3D, 입력 UX |
| 데이터+화면 | 관성 | 가상 학생·식단·통학 데이터 생성, 입력→결과 화면 |
| UX·발표 | 승빈 | 화면 설계·비주얼, 발표자료·시연영상 |

발표: 5분 + Q&A 3분 (발표자: 심주영)

## 데이터 흐름

```
        ┌─ AI (품목·수량 추출) ──┐
입력 ───┤                       ├──→ 계산엔진(×계수 / 통합) ──→ 3D 행성 반영
        └─ 가상데이터 / DB ──────┘
                                      ↑
                           프론트 연결 / 디자인
```
